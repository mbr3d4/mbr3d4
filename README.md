## Engineering Principles

My projects follow a consistent experimental workflow:

`Problem → Hypothesis → Experiment → Measurement → Evidence → Learning`

Each substantive project aims to provide:

- A clearly defined problem and testable hypothesis.
- Reproducible setup and execution instructions.
- Explicit baselines, variables, and evaluation criteria.
- Measured results, including unsuccessful experiments.
- Limitations, threats to validity, and next steps.
- Tests and evidence that allow others to inspect the conclusions.

I distinguish measured facts from interpretation and avoid claiming improvements that the available evidence does not support.
